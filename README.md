# devnetgroup-EventAttendance
# BSIT 3B

# This is a Python Flask REST API developed for the IT31DEVNET Activity. It manages student attendance for campus organization events by allowing attendee registration, recording ON_TIME, LATE, and OUT attendance phases, retrieving records, and generating attendance summaries. This demonstrates REST API development, JSON data handling, HTTP methods, error handling, and collaborative development using GitHub branches and pull requests.
